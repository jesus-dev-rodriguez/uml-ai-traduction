# Glosario Técnico de Referencia: UML 2.5.1 (Inglés -> Español)

Este glosario técnico define los términos normalizados para la traducción y adaptación de la especificación oficial de UML 2.5.1. Toda traducción generada por los agentes debe adherirse estrictamente a estas equivalencias para mantener la coherencia a lo largo de todo el documento.

| Término en Inglés | Traducción Oficial | Notas / Contexto |
| :--- | :--- | :--- |
| **Abstract Syntax** | Sintaxis Abstracta | La estructura lógica del lenguaje independiente de la representación visual. |
| **Abstraction** | Abstracción | Una relación de dependencia que relaciona dos elementos en diferentes niveles de detalle. |
| **Action** | Acción | La unidad fundamental de comportamiento ejecutable. |
| **Activity** | Actividad | Especificación de comportamiento parametrizado mediante flujo de control y datos. |
| **Actor** | Actor | Entidad externa que interactúa con el sistema. |
| **Aggregation** | Agregación | Forma de asociación que representa una relación todo-parte (asociación débil). |
| **Association** | Asociación | Relación semántica entre clasificadores que describe conexiones entre instancias. |
| **Association Class** | Clase Asociación | Una asociación que también posee propiedades de una clase. |
| **Attribute** | Atributo | Propiedad estructural de un clasificador. |
| **Behavior** | Comportamiento | Especificación de cómo cambian los estados o de las acciones de un elemento en el tiempo. |
| **Boundary** | Frontera / Límite | Límites de un sistema u objeto en diagramas de interacción/casos de uso. |
| **Call Event** | Evento de Llamada | Un evento que representa la recepción de una solicitud para llamar a una operación. |
| **Class** | Clase | Clasificador que describe un conjunto de objetos con idénticos atributos, operaciones y relaciones. |
| **Classifier** | Clasificador | Categoría de elementos de modelo que poseen características estructurales y de comportamiento. |
| **Collaboration** | Colaboración | Cooperación entre roles para lograr un objetivo común. |
| **Component** | Componente | Clasificador modular que encapsula su contenido y se comunica mediante interfaces. |
| **Composition** | Composición | Agregación fuerte donde la vida de la parte está ligada a la vida del todo. |
| **Constraint** | Restricción | Condición o regla semántica que se aplica a elementos del modelo (suele expresarse en OCL). |
| **DataType** | Tipo de Datos | Clasificador cuyos valores se identifican únicamente por su identidad de valor. |
| **Dependency** | Dependencia | Relación en la que un elemento cliente requiere de otro elemento proveedor. |
| **Deployment** | Despliegue | Asignación de artefactos a nodos de ejecución física o lógica. |
| **Diagram** | Diagrama | Representación gráfica de una parte del modelo. |
| **Element** | Elemento | El constituyente básico de un modelo; casi todo en UML es un Elemento. |
| **Encapsulated Classifier** | Clasificador Encapsulado | Un clasificador estructurado que posee puertos para comunicación. |
| **Entity** | Entidad | Objeto persistente o elemento clave del dominio. |
| **Entry/Exit Point** | Punto de Entrada/Salida | Vértices de conexión para estados compuestos o máquinas de estados. |
| **Enumeration** | Enumeración | Tipo de datos cuyos valores consisten en una lista nombrada de literales. |
| **Event** | Evento | Especificación de una ocurrencia que puede desencadenar comportamientos. |
| **Execution Specification** | Especificación de Ejecución | Bloques de activación/foco de control en diagramas de secuencia. |
| **Feature** | Característica / Rasgo | Propiedad estructural o de comportamiento de un clasificador. |
| **Generalization** | Generalización | Relación taxonómica entre un clasificador más específico y uno más general. |
| **Guard (Guard Condition)** | Guarda / Condición de Guarda | Expresión booleana asociada a una transición o flujo que debe ser verdadera para habilitarse. |
| **Interface** | Interfaz | Clasificador que declara un conjunto de características públicas (contrato). |
| **Interface Realization** | Realización de Interfaz | Relación que indica que un clasificador cumple con el contrato de una interfaz. |
| **Lifeline** | Línea de Vida | Representación de un participante individual en una interacción. |
| **Link** | Enlace | Instancia de una asociación. |
| **Message** | Mensaje | Especificación de una comunicación entre líneas de vida en una interacción. |
| **Metaclass** | Metaclase | Una clase cuyas instancias son ellas mismas clases o elementos de modelo. |
| **Multiplicity** | Multiplicidad | Definición del rango de cardinalidades permitidas para una propiedad o extremo de asociación. |
| **Namespace** | Espacio de Nombres | Elemento que puede contener a otros elementos con nombres únicos. |
| **Node** | Nodo | Recurso de ejecución computacional sobre el cual se pueden desplegar artefactos. |
| **Object** | Objeto | Instancia concreta de una clase. |
| **Operation** | Operación | Característica de comportamiento que puede ser invocada y posee una firma. |
| **Package** | Paquete | Elemento de agrupación para organizar otros elementos de modelo. |
| **Parameter** | Parámetro | Especificación de un argumento de entrada, salida o retorno en una firma. |
| **Pin** | Pin | Un nodo de objeto en actividades para pasar argumentos a acciones. |
| **Port** | Puerto | Punto de interacción entre un clasificador encapsulado y su entorno. |
| **PrimitiveType** | Tipo Primitivo | Tipo de datos predefinido sin estructura interna visible (ej. Integer, String, Boolean). |
| **Profile** | Perfil | Mecanismo de extensión personalizado para dominios específicos. |
| **Property** | Propiedad | Característica estructural de un clasificador (o extremo de una asociación). |
| **Protocol State Machine** | Máquina de Estados de Protocolo | Máquina de estados que define el orden de invocación de operaciones permitidas. |
| **Reception** | Recepción | Declaración de que un clasificador está preparado para reaccionar ante una señal. |
| **Relationship** | Relación | Elemento que conecta a otros elementos en un modelo. |
| **Signal** | Señal | Especificación de un estímulo asíncrono transmitido entre instancias. |
| **State** | Estado | Condición o situación de un objeto durante su vida en la que satisface alguna condición. |
| **State Machine** | Máquina de Estados | Especificación de comportamiento mediante secuencias de estados y transiciones. |
| **Stereotype** | Estereotipo | Definición de una extensión de metaclase dentro de un perfil. |
| **Structured Classifier** | Clasificador Estructurado | Clasificador con estructura interna de partes conectadas y puertos. |
| **Transition** | Transición | Relación entre dos vértices en una máquina de estados desencadenada por eventos. |
| **Use Case** | Caso de Uso | Especificación de un conjunto de acciones que un sistema realiza para entregar un valor. |
| **Visibility** | Visibilidad | Nivel de acceso a un elemento de modelo (public, private, protected, package). |
